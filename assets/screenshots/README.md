# StrumSense Assets Directory

This directory stores visual assets for the repository and documentation.

## Expected Files:
- `banner.png`: Promotional project banner (recommended: 1280x400).
- `screenshots/live_tracking_hud.png`: Real-time HUD view of webcam with chord/strum direction overlay.
- `screenshots/newbie_ghost_chords.png`: Newbie Mode UI showing 2D ghost-chord diagrams.
- `screenshots/session_timeline.png`: Session recording analytics timeline.
- `screenshots/pdf_exporter.png`: Pro Mode chord-sheet PDF exporter view.
